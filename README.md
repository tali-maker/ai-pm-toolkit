# ai-pm-toolkit

This repo is a practical toolkit for product managers who use AI in day-to-day PM work—templates, prompts, and workflows you can copy into Cursor or your stack. It is for PMs, founders, and builders who want repeatable artifacts (PRDs, discovery, roadmaps, stakeholder updates) without starting from a blank page. Over time it will hold Cursor skills and rules, document templates, example automations, and lightweight guides for common PM tasks.
